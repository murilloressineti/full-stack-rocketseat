# API - Rocketseat Full-Stack

A **API** é um projeto que simula uma aplicação de e-commerce, permitindo a gestão de produtos, como criação, listagem e exclusão. Este projeto foi desenvolvido para aprimorar o conhecimento em **Node.js**, com foco na criação de um servidor HTTP, gerenciamento de rotas e manipulação de dados em arquivos JSON.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução para o servidor.
- **Insomnia**: Cliente de API para testar as requisições.
- **Git e GitHub**: Controle de versão e hospedagem do código.
