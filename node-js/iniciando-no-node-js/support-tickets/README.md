# API - Tickets

A **API de Tickets** é um projeto que simula a gestão de chamados (tickets), permitindo a criação, listagem, atualização de status e remoção de registros.  
Este projeto foi desenvolvido para praticar conceitos de **Node.js**, com foco em servidor HTTP nativo, gerenciamento de rotas e manipulação de dados em arquivos JSON.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução para o servidor.
- **Insomnia**: Cliente de API para testar as requisições.
- **Git e GitHub**: Controle de versão e hospedagem do código.
