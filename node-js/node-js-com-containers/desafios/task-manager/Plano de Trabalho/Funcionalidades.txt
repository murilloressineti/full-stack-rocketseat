📌 Plano de trabalho por funcionalidades
1. Autenticação e Autorização
 - Signup (POST /users) → criar usuário (name, email, senha hash, role default = member).✅
 - Login (POST /sessions) → autenticação com email/senha, geração de JWT.✅
 - Middleware ensureAuthenticated → valida JWT e adiciona req.user.✅
 - Middleware verifyUserAuthorization → checa role (admin ou member).✅

2. Gerenciamento de Usuários (Admin)
 - Listar usuários (GET /users) — apenas admin.✅
 - Visualizar usuário (GET /users/:id) — admin ou o próprio usuário.✅
 - Editar usuário (GET /users/:id) — admin ou o próprio usuário.✅
 - Deletar usuário (DELETE /users/:id) — apenas admin.✅

3. Gerenciamento de Times
 - Criar time (POST /teams) — admin.✅
 - Listar times (GET /teams) — admin ou membro.✅
 - Editar time (PUT /teams/:id) — admin.✅
 - Deletar times (DELETE /users/:id) — admin✅
 - Adicionar membro ao time (POST /teams/:id/members) — admin.✅
 - Remover membro do time (DELETE /teams/:id/members/:userId) — admin.✅

4. Gerenciamento de Tarefas
 - Criar tarefa (POST /tasks) — admin pode criar para qualquer membro, member só pode criar para si dentro de um time.✅
 - Listar tarefas (GET /tasks) — ✅
    - admin: vê todas.
    - member: só as do time dele.
 - Visualizar tarefa (GET /tasks/:id) — admin ou membro que pertence ao time.✅
 - Editar tarefa (PUT /tasks/:id) —✅
    - admin: pode editar qualquer.
    - member: só pode editar se for atribuída a ele.
 - Deletar tarefa (DELETE /tasks/:id) — admin.✅

5. Task History
 - Registro automático: ao mudar status de uma task, criar registro no TasksHistory.
 - Listar histórico da tarefa (GET /tasks/:id/history).

Users → Teams → TeamMembers → Tasks → TasksHistory
