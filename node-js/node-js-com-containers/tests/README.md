# API - Testes Unitários com Jest

A **API - Testes Unitários com Jest** é um projeto focado em demonstrar a implementação de **testes unitários** usando o framework **Jest.** A aplicação serve como um ambiente prático para aprender a testar pequenas partes isoladas do código, garantindo sua funcionalidade correta e facilitando a manutenção.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução do servidor.
- **TypeScript**: Superset do JavaScript com tipagem estática.
- **Jest:** Framework de testes unitários para JavaScript e TypeScript.
- **Git e GitHub**: Controle de versão e hospedagem do código.
