# ORM com Prisma

A **API - ORM com Prisma** é um projeto desenvolvido para demonstrar a utilização do **Prisma** como um **Object-Relational Mapper (ORM).** A aplicação se conecta a um banco de dados e permite a interação de forma mais intuitiva e segura, sem a necessidade de escrever SQL puro. O objetivo principal deste projeto é apresentar como o Prisma simplifica operações de banco de dados, como **consultas, inserções e atualizações,** oferecendo um fluxo de trabalho com foco em segurança de tipos e produtividade para desenvolvedores.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução para o servidor.
- **TypeScript**: Superset do JavaScript com tipagem estática.
- **Prisma**: ORM para manipulação do banco de dados.
-- **PostgreSQ**: Banco de dados relacional.
- **Git e GitHub**: Controle de versão e hospedagem do código.
