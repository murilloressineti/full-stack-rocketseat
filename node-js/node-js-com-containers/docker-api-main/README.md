# Docker

Este projeto é uma API Node.js simples que retorna a mensagem "Hello World!". Ele foi desenvolvido para demonstrar a utilização do **Docker** para conteinerização de aplicações, garantindo que o ambiente de execução seja consistente e facilmente reproduzível.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução para o servidor.
- **Docker**: Plataforma de conteinerização.
- **Git e GitHub**: Controle de versão e hospedagem do código.
