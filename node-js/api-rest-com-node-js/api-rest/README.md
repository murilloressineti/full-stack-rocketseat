# API REST

A **API REST** é um projeto que simula uma aplicação de e-commerce, permitindo a gestão de produtos, como criação, listagem e exclusão.  
Este projeto foi desenvolvido para aprimorar o conhecimento em **Node.js com TypeScript**, com foco na tipagem estática, organização de rotas, controllers e tratamento de erros.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução para o servidor.
- **TypeScript**: Superset do JavaScript com tipagem estática.
- **Insomnia**: Cliente de API para testar as requisições.
- **Git e GitHub**: Controle de versão e hospedagem do código.
