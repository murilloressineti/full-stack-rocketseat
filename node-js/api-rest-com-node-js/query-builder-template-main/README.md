# API - Cursos e Módulos

A **API de Cursos e Módulos** é um projeto desenvolvido em Node.js com TypeScript para gerenciar cursos e seus respectivos módulos. A aplicação permite operações de criação, leitura, atualização e exclusão (CRUD) para cursos e módulos. 

O projeto usa **Knex.js** para interação com um banco de dados **SQLite** e inclui **migrations** para gerenciar a estrutura do banco de dados e **seeds** para popular as tabelas.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as tecnologias utilizadas no desenvolvimento deste projeto:

- **Node.js**: Ambiente de execução do servidor.
- **TypeScript**: Superset do JavaScript com tipagem estática.
- **Express.js**: Framework para a criação da API.
- **SQLite**: Banco de dados relacional utilizado.
- **Knex.js**: Query builder para manipulação do banco de dados.
- **Migrations e Seeds**: Controle de versionamento e inserção inicial de dados.
- **Insomnia**: Testes de rotas e requisições.
- **Git e GitHub**: Controle de versão e hospedagem do código.
