# Projetos com Responsividade - Rocketseat Full-Stack

Esta pasta reúne os projetos desenvolvidos durante o curso **Full-Stack** da **Rocketseat** que receberam aprimoramentos focados em **responsividade**. Cada projeto apresenta uma interface adaptável a diferentes tamanhos de tela, garantindo uma boa experiência em dispositivos móveis e desktops.

Todos os projetos utilizam **HTML semântico**, **CSS moderno** e seguem boas práticas de organização de código. Os layouts foram baseados em protótipos criados no **Figma**, e o versionamento foi feito com **Git** e **GitHub**.
