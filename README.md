# Materiais de Estudo - Rocketseat Full-Stack

Este repositório é dedicado ao meu aprendizado e aos projetos que estou desenvolvendo no curso **Full-Stack** da **Rocketseat**. Aqui, você encontrará uma coleção de códigos, desafios e projetos de diversas tecnologias que utilizo durante minha jornada como desenvolvedor. Este repositório reflete a evolução do meu aprendizado nas áreas de **Frontend**, **Backend**, **JavaScript**, **Node.js**, **React**, **Banco de Dados**, entre outros.

## 📚 **Sobre o Curso**

O curso Full-Stack da Rocketseat oferece uma formação completa para o desenvolvimento de sistemas web. O conteúdo é focado em **JavaScript**, **Node.js**, **React** e **Banco de Dados**, preparando os alunos para construir soluções modernas e eficientes. Ao longo do curso, faço projetos práticos e desafios que simulam situações reais do mercado de trabalho.

---

## 🛠 **Tecnologias e Ferramentas**

Aqui estão as principais tecnologias que venho utilizando nos meus projetos:

- **Frontend**: React, HTML, CSS, JavaScript, Tailwind CSS
- **Backend**: Node.js, Express, API Rest
- **Banco de Dados**: PostgreSQL, MySQL, MongoDB, Prisma ORM, Knex.js
- **Versionamento**: Git e GitHub
- **Outras**: TypeScript, Testes Automatizados

## 💻 **Projetos e Exercícios**

Este repositório contém os seguintes tipos de materiais:

- **Projetos**: Aplicações e sistemas completos que aplicam o conhecimento adquirido.
- **Desafios Práticos**: Desafios de aprendizado e prática, focados em fundamentos e conceitos essenciais.
